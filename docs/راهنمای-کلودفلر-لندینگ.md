# راه‌اندازی لندینگ رایگان با Cloudflare Pages

این راهنما برای پروژهٔ Metrico است. پوشهٔ لندینگ:

`landing/`

اپلیکیشن فعلاً روی GitHub Pages می‌ماند؛ لندینگ روی Cloudflare با آدرس رایگان `*.pages.dev` منتشر می‌شود.

---

## چرا من نمی‌توانم به‌جای تو وارد داشبورد شوم

ساخت حساب، ورود، و اتصال GitHub به Cloudflare **باید با ایمیل و رمز خودت** انجام شود (امنیت). من لندینگ را در مخزن آماده کردم؛ تو فقط چند کلیک در داشبورد می‌زنی.

---

## مرحله ۱ — ثبت‌نام (رایگان)

1. برو به:

   `https://dash.cloudflare.com/sign-up`

2. ایمیل و رمز بساز؛ حساب **Free** کافی است.

---

## مرحله ۲ — push لندینگ به GitHub

قبل از Pages، فایل‌های `landing/` باید روی GitHub باشند (commit + push). اگر خواستی من در چت بعدی push کنم بگو.

---

## مرحله ۳ — ساخت پروژه Pages

1. ورود به داشبورد:

   `https://dash.cloudflare.com`

2. منو: **Workers & Pages** → **Create** → **Pages** → **Connect to Git**

3. **GitHub** را authorize کن.

4. مخزن را انتخاب کن:

   `mehrzad1420/metrico_by_cursor`

5. تنظیمات build (مهم):

   | فیلد | مقدار |
   |------|--------|
   | Project name | `metrico-landing` (یا هر نام) |
   | Production branch | `main` |
   | Framework preset | **None** |
   | Build command | خالی بگذار |
   | Build output directory | `landing` |

6. **Save and Deploy** — بعد از ۱–۲ دقیقه لندینگ live می‌شود.

---

## مرحله ۴ — آدرس رایگان

Cloudflare یک URL می‌دهد، شبیه:

`https://metricoapp.pages.dev`

این را در pitch و کارت ویزیت بگذار. دکمهٔ «ورود به اپ» همان GitHub Pages اپ را باز می‌کند.

---

## مرحله ۵ — بعداً دامنهٔ پولی (اختیاری)

وقتی دامنه خریدی:

1. در همان پروژه Pages → **Custom domains** → Add domain  
2. DNS را طبق راهنمای Cloudflare تنظیم کن (اغلب nameserver به Cloudflare).  
3. گواهی SSL خودکار است.

---

## مرحله ۶ — زیردامنه برای اپ (اختیاری، بعداً)

مثلاً:

- `www` یا ریشه → لندینگ (Pages)  
- `app` → همان GitHub Pages یا مسیر دیگر  

فعلاً لازم نیست؛ دو لینک جدا هم برای دمو کافی است.

---

## عیب‌یابی

- **صفحه ۴۰۴:** مطمئن شو **Build output directory** دقیقاً `landing` است (نه `/landing`).  
- **لوگو نمی‌آید:** `landing/logo.png` باید در گیت باشد.  
- **build fail:** دستور build باید خالی باشد (سایت纯 HTML است).

---

## خلاصه

| مورد | هزینه |
|------|--------|
| Cloudflare Pages | رایگان |
| SSL | رایگان |
| `*.pages.dev` | رایگان |
| دامنه `.com` | بعداً ~۱۰–۱۵ یورو/سال |
